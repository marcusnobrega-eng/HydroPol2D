Stanford 30 m Excel inputs

Run this case from the repository root with:

    run('Examples/Stanford/run_excel.m')

Keep the workbook names and the existing columns unchanged. Edit values only
where needed. Raster paths in General_Data.xlsx are relative to this folder
and point to ../Static/.

The supplied rainfall is 100 mm/h from 0 to 60 minutes. The simulation
continues to 180 minutes so the runoff hydrograph can propagate and recede.

See ../README.md for the equivalent MATLAB-code launcher and the complete
folder description.
