# Application Workflows

This directory groups optional workflows developed for particular applications. The standard model launcher is [`HydroPol2D_V115.m`](../HydroPol2D_V115.m); examples and validation cases do not require these utilities.

| Folder | Purpose |
| --- | --- |
| [`HPC`](HPC/README.md) | SLURM batch template for running the standard model on a compute cluster. |
| [`SNISB`](SNISB/README.md) | Batch runners for prepared Brazilian dam-break case folders. |

Each workflow has its own inputs, assumptions, and execution instructions in its folder README.
